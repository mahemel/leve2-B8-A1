# Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment demonstrates practical knowledge of TypeScript fundamentals and Object-Oriented Programming (OOP). It includes solutions for type annotations, optional parameters, type narrowing, readonly tuples, generics, interfaces, Promises, classes, access modifiers, and asynchronous programming.

All coding solutions are implemented in a single file named `solutions.ts`. The functions and classes follow the required naming conventions, explicit parameter and return types, and exact output formats.

## Blog Posts

Two technical blog posts are included as part of the assignment:

- [Type Aliases vs. Interfaces in TypeScript](./type-vs-interface.md)
- [Access Modifiers in TypeScript OOP](./access-modifiers.md)
